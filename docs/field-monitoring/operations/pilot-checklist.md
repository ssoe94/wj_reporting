| ☐ 서버·권한 | 승인된 배포 버전과 마이그레이션을 확인합니다. 조회 권한 계정은 현황·예외·검색·CSV를 열고, 관리 권한 계정만 등록·발급·회수합니다. 승인된 시험 PC의 heartbeat 및 합성·시험 이벤트를 확인합니다. | 核对批准的部署版本与迁移。查询账号可查总览、异常、记录与 CSV，只有管理账号能登记、签发及撤销。核对获准测试电脑的心跳和测试事件。 |
| ☐ 설치·복귀 | EXE·설정·DB 백업을 별도 경로에서 검증합니다. 한글·공백 경로에서 ZIP 검증, 설치, 바로가기, 업데이트, 이전 버전 복귀를 시험합니다. 불일치 해시·미전송 인쇄·열린 사이클에서 전환 보류, 원장·백업·설정·토큰 보존을 확인합니다. | 在独立位置验证旧 EXE、配置和数据库备份。在含韩文及空格的路径测试校验、安装、快捷方式、升级和回滚。验证校验值不符、待发打印或周期未关闭时阻止切换，并保留台账、备份、配置和令牌。 |
| ☐ 사용자·배치·언어 | 실제 작업자 계정의 로그온 자동 시작과 장애 재시작을 확인합니다. 단일·다중 모니터, 100%·125%, 작업표시줄·모니터 제거, 960×1000 전후에서 열기·다시 열기·포커스를 확인합니다. 양면 촬영은 반화면, V49·UV는 전체 화면과 배경 전송을 확인합니다. 한·중 전환, 앱 재시작과 브라우저 데이터 삭제 후의 선택 유지 여부를 앱별로 기록합니다. | 用实际操作员账号验证登录自启及异常重启。核查单屏、多屏、100%/125% 缩放、任务栏、移除显示器及约 960×1000 时的打开、重开和焦点。验证双面拍摄半屏、V49 和 UV 全屏及后台发送。逐程序记录中韩切换、重启及清除浏览器数据后是否保留选择。 |
| ☐ 병행 수집·전환 | 기존 앱이 장치를 소유할 때 읽기 전용 수집과 소스 단절을 확인합니다. 장치 교대 때 기존 앱·송신기를 정상 종료한 뒤 COM·프린터 점유를 확인합니다. 기록을 중앙에서 PC·앱·모드별로 대조합니다. | 旧程序独占设备时验证只读采集和数据源中断。切换时先正常退出旧程序与发送器，核查串口和打印机占用。按电脑、程序及模式比较中央记录。 |
| ☐ 바코드 | 승인 표본으로 A/B·ANY·반대 포트·제품군·길이·중복을 확인합니다. 같은 USB 위치에 재연결합니다. 승인 초기화 후 기존 정상 라벨 재스캔과 중앙 예외, NG 안내음·시각 표시를 확인합니다. | 用批准样件验证 A/B、ANY、错误端口、产品组、长度和重复。重插原 USB 位置。验证批准清零后重扫已通过标签及中央异常，并检查 NG 声音和视觉提示。 |
| ☐ 중량·인쇄 | 빈 저울·안정·허용 경계, 승인 치수와 라벨 문구, 실기 USBPRINT/RAW 또는 TCP, 박리·신호등, A/B/W 및 키보드 웨지를 확인합니다. 인쇄 불확실 뒤 재시작·일시정지·실물 확인과 재개를 시험합니다. 최초 시리얼 근거와 동일 PART의 발급 충돌 여부를 확인합니다. 기존 라벨 편집·보정 도구가 필요한 작업도 확인합니다. | 核查空秤、稳定、容差边界、批准的尺寸与标签文字、实际 USBPRINT/RAW 或 TCP、揭标、信号灯、A/B/W 及键盘扫码。验证打印不确定后重启、暂停、实物核查及恢复。核对首号依据及同料号发号冲突，并确认是否需要旧版标签编辑或校准功能。 |
| ☐ 발급 주체·이전 | 한 네임스페이스·PART에 PC·프로그램 하나만 등록하고, 배정 외 PART를 온라인·오프라인에서 예약할 때 현장 차단 사유와 이벤트를 확인합니다. 정책 누락·과다 허용을 각각 주입해 중앙 경고·예외를 검사합니다. 이전 PC의 중지 확인 전 해제 거절, 정책 적용·전송 완료 뒤 해제, 이전 PC의 오래된 정책 재적용 거절과 새 PC의 첫 번호가 날짜별 상한을 넘는지 확인합니다. 취소·불확실 예약을 상한에 포함합니다. [담당 이전](issuer-transfer.md) | 每个命名空间及料号只登记一台电脑及一个程序。在线与离线尝试预留未分配料号，核查现场阻止原因及事件。分别用漏配和多配策略检查中央告警及异常。验证确认原电脑停发前拒绝解除、策略应用且发送完成后可解除、拒绝重新应用旧策略，以及新电脑首号超过对应日期上限。已取消及不确定的预留也计入上限。[发号交接](issuer-transfer.md) |
| ☐ 다중 발급 감지 | 두 시험 PC의 동일 PART 예약과 서로 다른 PC의 동일 바코드 정상 스캔·재리딩을 재현해 각각 예외가 뜨는지 확인합니다. 외부 주체를 등록한 PART는 에이전트에서 차단하고, 외부 원본의 발급 중지는 별도로 확인합니다. | 重现两台测试电脑预留同一料号，以及不同电脑正常扫描或复读同一条码，分别确认出现异常。登记外部主体的料号应在代理端受阻，另行确认外部原程序已停发。 |
| ☐ V49 | 승인 표본의 정상·NG·중단·카메라와 신호등 장애, 영상 재생 제외, 같은 사이클의 상충 기록 확인을 시험합니다. 첫 시범은 상태 조회를 끕니다. 선택 활성화 시 검사 주기·지연·CPU·디스크의 전후 값을 기록합니다. | 用批准样件验证正常、NG、中止、相机和信号灯故障、回放不入生产统计及周期冲突记录。初次试用关闭状态查询。拟开启时，记录开启前后的检测周期、延迟、CPU 和磁盘读写。 |
| ☐ 양면·UV | 양면 앞·뒤 저장, 단독·앞면 보류·품번 배정, 한 쌍 건수를 확인합니다. UV 실물 표본으로 슬롯별 결과·수동/데모·재검사, 화면 최소 크기(1040×690 논리 px), 별도 한·중 패치 설치와 복귀를 확인합니다. | 验证正反面保存、单张、仅有正面时待确认、料号分配及配对条数。用 UV 实物样件验证各槽位判定、手动/演示和复检，检查窗口最小尺寸（1040×690 逻辑像素）、独立中韩补丁安装及恢复。 |
| ☐ 단절·복원·부하 | 생산 집계와 분리한 시범 조건에서 통신을 끊고 입력·복구·ACK·중복 여부를 확인합니다. 데이터 여유·백업·별도 경로 복원과 원장/중앙 대조를 실시합니다. 실제 Windows에서 유휴/작업 CPU·RSS·디스크·판정 지연을 기록합니다. | 在与生产统计隔离的条件下断网，并验证输入、恢复、ACK 和重复情况。检查剩余空间、备份、独立路径恢复，并对照台账与中央记录。在实际 Windows 上记录空闲及作业 CPU、RSS、磁盘和判定延迟。 |
