# 바코드 PC 작업자 카드 · 条码电脑操作卡

바탕화면 **WJ Field Agent Portable**에서 앱을 열고 오른쪽 위에서 **한국어 / 中文**을 선택합니다.\
在桌面打开 **WJ Field Agent Portable**，在右上角选择 **한국어 / 中文**。

| 한국어 | 简体中文 |
| --- | --- |
| **시작 전** · 생산/시험 모드, 제품군, A/B 배정을 확인합니다. 시험 입력에는 시험 모드를 사용합니다. 연결된 포트와 마지막 실제 입력 시각을 따로 확인합니다. | **开工前** · 确认生产/测试模式、产品组和 A/B 分配。测试扫码使用测试模式。分别检查端口连接状态和最后一次实际输入时间。 |
| **스캔 후** · 해당 A/B의 최근 판정과 바코드를 확인합니다. 정상은 화면 판정으로 확인합니다. 제품군 규칙상 ANY면 배정된 어느 쪽에서나 읽습니다. | **扫码后** · 在对应的 A/B 一栏核对最近判定和条码。以屏幕的正常判定为准。产品组规则为 ANY 时，可使用任一已分配的扫码器。 |
| **NG·중복** · 제품은 따로 두고 화면의 길이·제품군·스캐너·중복 사유를 확인합니다. 정확한 라벨과 배정으로 확인한 뒤에도 NG면 반장에게 알립니다. 스캐너 자체 소리로 정상 처리하지 않습니다. | **NG 或重复** · 隔离产品，查看长度、产品组、扫码器或重复原因。确认标签与设备分配无误后仍为 NG，请通知班组长。扫码器响声不能作为放行依据。 |
| **전송·장치 경고** · 전송이 밀리면 PC ID·시각·사유를 알립니다. 로컬 판정과 저장이 정상일 때만 현장 기준대로 계속합니다. 로컬 저장 실패나 장치 입력 중단이면 작업을 멈춥니다. | **发送或设备告警** · 出现待发送积压时，报告电脑 ID、时间和原因。本机判定和保存正常时，按现场规定继续。保存失败或设备输入中断时停止作业。 |
| **초기화** · 승인된 새 작업 구간을 열 때만 사용합니다. 초기화 뒤에는 직전 구간의 정상 라벨도 다시 정상 처리될 수 있습니다. 중복 경고를 없애려고 초기화하거나 장부·설정 파일을 지우지 않습니다. | **清零** · 仅在批准开启新作业区间时使用。清零后，上一区间已通过的条码可能再次判为正常。禁止为消除重复告警而清零，禁止删除台账或配置文件。 |
