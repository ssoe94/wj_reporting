# 비전 PC 작업자 카드 · 视觉电脑操作卡

V49 백커버·UV는 전체 화면이며, 양면 촬영은 배정된 반화면에서 실행합니다.\
V49 后盖及 UV 使用全屏，双面拍摄在分配的半屏运行。

| 한국어 | 简体中文 |
| --- | --- |
| **V49 백커버** · 품목·프로필과 카메라를 확인합니다. 제품 반출 후 확정 판정을 확인합니다. 가림 작업 미확인·검사 미완료·FAULT면 제품을 따로 두고 사이클 ID와 사유를 반장에게 알립니다. 진행 단계만 보고 제품을 넘기지 않습니다. | **V49 后盖** · 确认产品、配置及相机。产品移出后查看最终判定。遮挡操作未确认、检查未完成或 FAULT 时，隔离产品并向班组长报告周期 ID 和原因。禁止仅凭过程状态放行。 |
| **양면 촬영** · 품번·배정 출처를 확인하고 화면의 앞면→뒤집기→뒷면 순서대로 진행합니다. 두 면 저장을 확인합니다. 앞면만 남거나 배정이 다르면 제품을 따로 두고 쌍 ID를 알립니다. 파일을 손으로 옮기거나 이름을 바꾸지 않습니다. | **双面拍摄** · 核对料号和分配来源，按正面→翻面→背面的顺序操作，并确认两面已保存。仅保存正面或分配不符时，隔离产品并报告配对 ID。禁止手动移动文件或改名。 |
| **UV 배치** · 승인 레시피와 위치를 확인합니다. 배치 및 위치별 판정이 나오면 NG 위치를 따로 두고 배치 ID·위치·알람을 알립니다. 재검사는 승인 절차에 따라 새 배치로 실행합니다. 데모 화면을 생산 판정에 사용하지 않습니다. | **UV 批次** · 确认批准的配方及槽位。批次和各槽位判定完成后，隔离 NG 槽位产品并报告批次 ID、槽位及报警。获准复检后启动新批次。禁止把演示结果用于生产判定。 |
| **비전 수집 현황** · 필요할 때 **WJ Field Agent Portable - Status** 바로가기에서 기록 읽기·최근 작업·실행기 확인을 봅니다. 기록 읽기가 정상이면 확정 파일을 읽을 수 있다는 뜻입니다. 판정이나 장치 오류는 비전 앱 화면에서 확인합니다. | **视觉采集状态** · 需要时通过 **WJ Field Agent Portable - Status** 快捷方式查看记录读取、最近作业和启动器确认。读取正常表示可以读取已保存记录。判定及设备故障请在视觉程序中查看。 |
| **언어·경고** · 각 앱의 언어 메뉴를 사용합니다. UV 한·중 메뉴는 승인 패치판에 있습니다. 저장 오류나 장치 FAULT를 우회하지 말고 현장 대응 절차를 따릅니다. | **语言及告警** · 使用各程序内的语言菜单。UV 中韩选项随批准的补丁版提供。发生保存异常或设备 FAULT 时，按现场流程处理，禁止绕过。 |
