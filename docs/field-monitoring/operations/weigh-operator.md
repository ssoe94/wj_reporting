# 중량·라벨 PC 작업자 카드 · 称重和标签电脑操作卡

바탕화면 **WJ Field Agent Portable**에서 앱을 열고 **한국어 / 中文**을 선택합니다.\
在桌面打开 **WJ Field Agent Portable**，选择 **한국어 / 中文**。

| 한국어 | 简体中文 |
| --- | --- |
| **계량** · PART·모드·승인 템플릿을 확인합니다. 빈 저울이 안정된 뒤 제품을 올립니다. 최근 판정의 PART·중량·수량을 확인하고 다음 적재 전에 저울을 비웁니다. | **称重** · 确认料号、模式和批准的标签模板。空秤稳定后上料。查看最近判定的料号、重量和数量，下次上料前清空秤台。 |
| **계량 NG** · 제품을 따로 두고 사유를 확인합니다. 승인된 점검을 마친 뒤 빈 저울부터 다시 확인합니다. 허용값을 임의로 바꾸거나 NG 제품에 라벨을 붙이지 않습니다. | **称重 NG** · 隔离产品并核对原因。完成批准的检查后，从空秤重新确认。禁止自行调整容差或给 NG 产品贴标。 |
| **인쇄·재리딩** · 인쇄 큐의 대기·제출·박리·미확인을 확인합니다. 제출된 라벨은 실물 인쇄·부착과 해당 작업의 재리딩까지 확인합니다. 키보드형 리더는 전용 입력칸에 포커스를 둡니다. 실제로 꺼낸 라벨만 박리 확인합니다. | **打印和复扫** · 查看打印队列的等待、已提交、待取标和未确认状态。已提交的标签还需核查实际打印、粘贴及对应任务的复扫结果。键盘式扫码器须聚焦专用输入框。实际取走标签后才确认取标。 |
| **출력 불확실·일시정지** · 번호와 실물 수량을 대조해 **불확실 확인 기록**을 남깁니다. 반장 확인 후 대기 작업을 **전송 재개**합니다. 같은 행을 재인쇄하거나 확인한 수량을 추정 입력하지 않습니다. 잔량 출력은 승인 뒤 사용합니다. | **打印不确定或暂停** · 核对编号和实物数量，选择 **记录核查结果**。班组长确认后再 **恢复发送** 等待任务。禁止重打同一行或按估计填写数量。余量打印须经批准。 |
| **시리얼 기준·저장 오류** · 해당 PART 작업을 멈추고 관리자에게 알립니다. 번호를 직접 정하거나 동일 PART의 다른 발급 프로그램을 열지 않습니다. | **流水号基准或保存异常** · 暂停该料号作业并通知管理员。禁止自行指定编号或启动同料号的其他发号程序。 |
