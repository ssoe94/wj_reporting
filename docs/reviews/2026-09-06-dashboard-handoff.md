## 먼저 바꿀 것은 정보의 연결과 신뢰도

기본 홈 `/analysis`는 수기 보고서 기반이고, 최근 개발된 MES·생산계획·품질·재고·출고·에너지 자료는 다른 업무 화면과 종합 보드에 연결되어 있다. 새 수집 항목과 차트를 늘리기 전에 이 원천을 경영 판단과 현장 조치로 묶는다.

- **경영진:** 기준일·관측범위 → 생산 진도와 실적 확정 수준 → 납기·품질·설비 위험 → 영향 큰 확인 과제 → 비교 가능한 기간 추세.
- **실무진:** 오늘의 계획·실적 → 미확인 정지·무계획 가동·미대사 실적·생산 품번 미확정 → 원천 근거 → 담당자 조치와 종결.
- **현장:** 설비 칸반과 벽면 현황판의 목적을 유지한다. 관리용 정보를 공개 보드에 자동 추가하지 않는다.

두 기본 화면은 같은 지표 계약을 사용하되 요약 수준과 조치 기능을 달리한다. 권한 검사는 각 API와 경로에 그대로 적용한다.

## 이번 수정 범위

분석 홈과 현장 기록을 연결하고 생산 대시보드의 필수 원천 조회 실패를 생산 0건과 구분한다.

- `/analysis`를 MES·생산계획 기반 업무일 분석으로 연결한다. 근거와 수집 상태, 우선 확인 설비, 현장 불량 기록 요약을 제공한다. 종전 일보 기반 OEE·정규식 정지 분석은 새 홈에서 사용하지 않는다.
- 인증 GET `/api/analytics/field-operations/?date=YYYY-MM-DD`는 기존 `field-defects.v1` 체크포인트만 읽는다. 중복·겹친 구간·수량 불일치를 검증하고 미기록과 불량 0건 보고를 구분한다. 검사 불량률이나 확정 양품을 계산하지 않는다.
- 현장 모델체인지 확인에서 기존 정지 사유와 조치/인계 메모를 입력하고 당일 판정 기록을 다시 볼 수 있다. 기존 저장 API와 권한을 유지한다.

- 필수 원천은 실제 표시 수치에 사용되는 계획 요약·사출 MES·가공 MES·생산 실행 배분·가공 보정 실적 5개다. 공유된 타입과 원천 목록으로 누락을 방지한다.
- 최초 조회에 실패하면 수치와 브리핑을 보류하고 원천별 안내, 재시도, 날짜 변경을 제공한다.
- 성공했던 자료의 갱신이 실패하면 이전 자료와 마지막 성공 시각을 표시하고 최신 브리핑 판단을 보류한다.
- AI 설명만 실패하면 기존 결정적 계산 브리핑으로 전환한다.
- 한국어·중국어 문구와 기존 스타일을 사용한다.

생산 대시보드 수정은 HTTP 요청 상태를 구분한다. 새 분석 홈은 원천 상태와 내부 누락 경고도 해석하지만, 전체 앱의 공통 신선도 계약과 추정 배분·분모 문제를 모두 해결한 것은 아니다. 상세 후속 범위는 새 개발 계획을 따른다.

## 검증과 한계

생산 대시보드 상태 테스트 15개와 분석 근거 테스트 17개, 운영 설정을 로드하지 않는 메모리 SQLite의 현장 집계 테스트 13개가 통과했다. 최종 프런트엔드 빌드와 legacy 빌드, 린트(오류 0·기존 경고 31)가 통과했다. 백엔드 테스트 대상은 `analytics.test_field_operations`이며 Mac Studio에서도 운영 설정과 분리된 검증용 DB에서 실행한다. 전체 애플리케이션 검사와 배포 결과는 PR의 최종 검증 항목을 따른다. Vite의 큰 청크 경고는 별도 최적화 과제다.

초기 브라우저 탭 제어는 시간 초과했으나 이후 Chrome 앱 제어로 로그인된 운영 `/analysis`와 `/field/imm01` 화면을 확인했다. 새 화면은 로컬 개발 전용 로그인과 읽기 전용 프록시에서 확인했다. 날짜·오늘 버튼, 한중 전환, 경영/실무 전환, 설비별 기록 펼침, 초기 조회 실패·날짜별 캐시 분리·갱신 실패 시 이전값 보존, 390px 화면의 가로 넘침 방지를 검증했다. 현장 집계 정상 표시에는 명시적으로 합성한 테스트 자료를 사용하며 실제 생산 근거 자료와 혼합해 경영 판단에 사용하지 않는다. 현장판의 한중 전환과 당일 기록 창도 확인했고 운영 데이터 저장 버튼으로 시험 입력하지 않았다.

운영 중 실제 페이지 사용량은 확인되지 않았다. 파일명이나 placeholder만 보고 페이지를 삭제하지 않는다. 운영 DB 직접 조회·자격증명·환경 파일·배포 설정·마이그레이션은 이 변경 범위에 포함하지 않는다.
