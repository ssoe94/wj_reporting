## 먼저 바꿀 것은 정보의 연결과 신뢰도

기본 홈 `/analysis`는 수기 보고서 기반이고, 최근 개발된 MES·생산계획·품질·재고·출고·에너지 자료는 다른 업무 화면과 종합 보드에 연결되어 있다. 새 수집 항목과 차트를 늘리기 전에 이 원천을 경영 판단과 현장 조치로 묶는다.

- **경영진:** 기준일·관측범위 → 생산 진도와 실적 확정 수준 → 납기·품질·설비 위험 → 영향 큰 확인 과제 → 비교 가능한 기간 추세.
- **실무진:** 오늘의 계획·실적 → 미확인 정지·무계획 가동·미대사 실적·생산 품번 미확정 → 원천 근거 → 담당자 조치와 종결.
- **현장:** 설비 칸반과 벽면 현황판의 목적을 유지한다. 관리용 정보를 공개 보드에 자동 추가하지 않는다.

두 기본 화면은 같은 지표 계약을 사용하되 요약 수준과 조치 기능을 달리한다. 권한 검사는 각 API와 경로에 그대로 적용한다.

## 이번 수정 범위

생산 대시보드의 필수 원천 조회 실패를 생산 0건과 구분한다.

- 필수 원천은 실제 표시 수치에 사용되는 계획 요약·사출 MES·가공 MES·생산 실행 배분·가공 보정 실적 5개다. 공유된 타입과 원천 목록으로 누락을 방지한다.
- 최초 조회에 실패하면 수치와 브리핑을 보류하고 원천별 안내, 재시도, 날짜 변경을 제공한다.
- 성공했던 자료의 갱신이 실패하면 이전 자료와 마지막 성공 시각을 표시하고 최신 브리핑 판단을 보류한다.
- AI 설명만 실패하면 기존 결정적 계산 브리핑으로 전환한다.
- 한국어·중국어 문구와 기존 스타일을 사용한다.

이 수정은 HTTP 요청 상태를 구분한다. HTTP 200 응답 안의 수집 지연·부분 수집·잘못된 분모·실적 배분 추정까지 해결하는 것은 다음 단계다.

## 후속 구현 순서와 완료 조건

| 순서 | 작업 | 완료 조건 |
|---|---|---|
| P0 | 전 화면 공통 데이터 상태 계약 | `ready / empty / no_plan / partial / stale / error / forbidden`과 기준기간·원천시각·관측범위를 구별. 실패/미수집은 `—`, 검증된 0만 `0` |
| P0 | 집계와 지표 정의 수정 | 가공 분석의 첫 100건 제한과 날짜 덮어쓰기를 해결. 수기 OEE와 최신 보드의 정의를 통일. 분모가 없으면 OEE 계산 보류 |
| P1 | 경영 홈과 실무 운영 연결 | 기존 원천으로 조치 목록 5건과 근거 링크 제공. 데이터가 없는 지표는 원인·최근 자료·다음 행동을 표시 |
| P1 | 기존 확인 데이터 활용 | 정지/무계획활동/대사/품번 매칭의 미확인 건과 영향을 같은 목록에 노출. 확인 완료 후 목록/숫자 동기화 |
| P1 | 신선도와 확정 상태 | 집계 생성시각과 원천 최종시각을 분리. 저장 mart의 무조건 `is_stale=False` 제거. 상세·요약 간 원천/기간 일치 검증 |
| P2 | 메뉴 정리 | 입력 화면의 ‘대시보드’, 기록 화면의 ‘통계’ 명칭을 실제 역할에 맞춤. 기존 URL/북마크와 권한 보존 |

## 추가 수집은 기존 필드의 활용 여부를 먼저 점검

| 우선순위 | 필요한 데이터 | 기존 자료와 추가할 부분 | 가능해지는 판단 |
|---|---|---|---|
| 1 | 휴일·교대·예정가동·계획정지 | 현장 캘린더와 계획 버전 연결을 확인/보강 | 무계획의 이유, 유효 가동률 분모 |
| 1 | 수집 성공/실패와 기대 관측범위 | 기존 freshness에 작업 실행 상태·누락 설비/시간구간·지연 원인 연결 | KPI를 신뢰할 수 있는 범위 |
| 1 | 실적의 확정/추정/미대사, 작업지시·품번·LOT·금형 키 | MES/수기 대사·Cavity·품번 연결 구조를 먼저 활용 | 실적 차이의 원인과 확인 우선순위 |
| 2 | 조치 담당·기한·원인·종결·재발 | 기존 정지/활동 확인에 닫힌 조치 이력 연결 | 누가 무엇을 해결해야 하는지, 재발 여부 |
| 2 | 약속 납기와 실제 출하 이벤트 | 기존 출고 계획·누적 doneAmount를 활용하고 event 시각·부분출하·취소·당시 스냅샷 추가 | 납기 준수율/잔량. 계획 코호트 이행률을 정시납품률로 부르지 않음 |
| 3 | 표준 CT·양품/검사/폐기·단위·유효일 | PartSpec와 품질의 기존 필드 입력률/연결률 확인 후 부족 필드 보강 | 검증 가능한 OEE·불량률·생산성 |
| 3 | 단가·원가·BOM 단위환산·유효일 | 재고수량·에너지 실측에 재무 기준 연결 | 재고금액·손실금액·생산단위당 에너지비 |

최소 지표 계약은 `source, business_date, window_start/end, source_latest_at, fetched_at, coverage, actual_basis, numerator, denominator, unit, formula_version, warnings`를 포함한다. 금액 기준이 없을 때 재고수량을 재고금액으로, 검사 분모가 없을 때 품질 보고 건수를 불량률로 표시하지 않는다.

## 검증과 한계
